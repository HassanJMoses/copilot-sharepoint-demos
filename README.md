# Copilot in SharePoint demos

Working demos of Copilot in SharePoint for document-heavy, regulated work: skills, sample files, setup steps and the videos they appear in. Each demo runs on a plain SharePoint site with a Microsoft 365 Copilot licence, nothing else.

| Demo | What it shows | Status |
|---|---|---|
| [New Customer Packet](demos/new-customer-packet/README.md) | One button builds a branded insurance welcome packet from an application: selects by metadata, renders from HTML layouts, merges, reviews, sends | Working, [video 1](https://www.youtube.com/watch?v=xFWDL-QakWM) |

**This is a demo.** Every company, person, policy number, dollar figure and VIN in this repository is fictional, built for a product demonstration. Nothing here is a real insurance policy, offer of coverage, or legal, financial or insurance advice.

The skills are also published in the [PnP SharePoint Skills library](https://github.com/pnp/sharepoint-skills). This repository is the source: the full sample sets, the layouts, the setup and the story live here.
