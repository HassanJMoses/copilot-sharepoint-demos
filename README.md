# Copilot in SharePoint demos

Working demos of Copilot in SharePoint for document-heavy, regulated work: skills, sample files, setup steps and the videos they appear in. Each demo runs on a plain SharePoint site with a Microsoft 365 Copilot licence, nothing else.

| Demo | What it shows | Status |
|---|---|---|
| [New Customer Packet](demos/new-customer-packet/README.md) | One button builds a branded insurance welcome packet from an application: selects by metadata, renders from HTML layouts, merges, reviews, sends | Working, [video 1](https://www.youtube.com/watch?v=xFWDL-QakWM) |
| [Change Order Management](demos/construction-change-order/README.md) | Three buttons carry a construction change order through: assess the impact along the project's dependency chain, confirm and apply it with a contract addendum, notify every phase manager; a live dashboard and a schedule view inside a list | Working, [video 2](https://www.youtube.com/watch?v=oblKIcqcUDI) |

**This is a demo.** Every company, person, policy number, project, contract, dollar figure and VIN in this repository is fictional, built for a product demonstration. Nothing here is a real insurance policy, contract, offer of coverage, or legal, financial, insurance or construction advice.

The skills are also published in the [PnP SharePoint Skills library](https://github.com/pnp/sharepoint-skills). This repository is the source: the full sample sets, the layouts, the dashboards, the setup and the story live here.
