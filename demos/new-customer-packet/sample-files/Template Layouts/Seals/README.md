# State seals for the template documents

Rebuilt 2026-10-09 from the original SVG files on Wikimedia Commons: each SVG rendered at 1600 px with Edge (transparent background, nothing clipped), trimmed to the artwork, given an even 4% transparent margin so the outer ring never touches the image edge, and saved at 1200 x 1200 px. The earlier 960 px PNG renditions had the Florida and Louisiana rings running into the image edge, which showed as a cut-off circle. Each state's documents carry its seal in the banner (0.85in) or, on the proof of insurance cards, in the card (1.04in), embedded under a name unique to the state (tx_seal.png, fl_seal.png, la_seal.png).

Caution carried from every source page: "The use of such symbols is restricted in many countries. These restrictions are independent of the copyright status." State law can restrict use of an official seal regardless of copyright. These files are used only on synthetic demo documents for a fictional insurer. Do not use them on anything that could pass as a real state or carrier document. The canonical disclaimer wording (document footer, public repo README, and video description) is in `../../disclaimer.md`; the README version there already folds in this caution.

Source SVG: `https://commons.wikimedia.org/wiki/Special:FilePath/Seal_of_<State>.svg`. Render it larger than needed with its outer ring fully visible, trim to the artwork, pad about 4% on every side, and save square.
